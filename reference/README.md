# Aggregate Reference Outputs

This directory contains non-patient aggregate values used to audit the Round 2 manuscript and local reproductions.

In the v1.3.1 release, AUROC intervals are synchronized to the unchanged canonical `scripts/metric_intervals.py`. Internal intervals use DeLong, including the corrected reduced-model CI 0.718–0.874. Temporal and exploratory intervals use 2,000 class-stratified bootstrap resamples with seed 42: MIMIC-III benchmark 0.659–0.752, reduced 0.669–0.763; Third Xiangya 0.699–0.900; USC-FAH 0.826–0.954. Primary AUROC point estimates and Brier scores are unchanged. `r2/r2_standard_calibration_metrics.csv` and `r2/r2_corrected_mimic3_evaluation.csv` include the AUROC interval columns already generated by the canonical code. All model-fitting code is unchanged. See `docs/R3_CORRECTION_AUDIT.json`. The prior published v1.2.2 archive remains immutable; v1.3.1 is the current R3 release.

- `manifest.json`: current cohort and headline metric manifest.
- `table2_3_performance.csv`: locked benchmark and post hoc reduced-model performance.
- `r2/`: flow, calibration, missing-data, serum-iron, NIV-exclusion, observation-window, patient-unit, and synthetic-duration-proxy aggregate outputs.
- `r2/figure8_reviewed_interface.png`: reviewed Figure 8 interface rendering for the synthetic/default demonstration record; SHA-256 and expected 22.4% output are locked in `manifest.json`.

No row-level predictors, outcomes, probabilities, cohort identifiers, or fitted objects are included.
